# Requirements Catalog

| ID | Title | Description / User Story |
|---|---|---|
| FR-001 | Assign Task | As a user, I want to assign a task to another user so that work can be distributed. |
| FR-002 | Create Task | As a user, I want to create a task so that new work items can be tracked. |
| FR-003 | Update Task Detail | As a user, I want to update a task's details so that task information stays accurate. |
| FR-004 | Delete Task | As a user, I want to delete a task so that obsolete tasks are removed from active work. |
| FR-005 | View Task History | As a user, I want to view a task's history so that I can see what changes were made and by whom. |
| NFR-001 | Assignment Response Time | Assigning a task must complete in under 1 second. |
| C-001 | Platform Constraint | Backend must run on Java 21 and PostgreSQL 16. |
